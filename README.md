# OpenShieldNet

**OpenShieldNet** — это открытая экосистема на базе микроконтроллеров ESP32 и ESP8266 для создания физических интерактивных панелей, секторных щитов и центральных вычислительных узлов. 

Проект разработан для применения в сфере интерактивного реквизита, LARP (ролевых игр живого действия), лазертаг-площадок, квест-комнат и командных аттракционов. Система позволяет моделировать секторную защиту объектов, фиксировать физические попадания, отображать статус на графических дисплеях и координировать устройства по беспроводной сети UDP/Wi-Fi.

---

## 🚀 Основные возможности

* **Распределенная архитектура:** Центральный модуль (Main) на ESP32 управляет сетью до 5 перифрийных модулей (Shields) на ESP8266.
* **Фиксация физических попаданий:** Периферийные модули оснащены датчиками вибрации/удара с аппаратурной защитой от дребезга и повторных срабатываний.
* **Двусторонняя связь по UDP:** Автоматический поиск модулей в сети, отслеживание онлайн-статуса (Keep-Alive / Ping) и обработка команд в реальном времени.
* **Игровые механики выживания:**
  * Системы временной невосприимчивости к урону (Cooldown/Immunity).
  * Режим критической уязвимости при пробитии сектора (**Shield Fall**).
  * Автоматическая регенерация прочности.
  * Аварийный режим работы (**Lifeboat Mode**) с переключением на резервный сектор.
* **Графический HUD-интерфейс:** Вывод состояния системы, кольцевых таймеров и анимаций на графический дисплей (поддержка интерфейса ST7701S / RGB).
* **Инженерный веб-терминал:** Встроенный веб-сервер для мониторинга состояния щитов, ввода одноразовых кодов ремонта/апгрейда и настройки параметров игры.
* **Энергонезависимость:** Все параметры настройки и состояние игры сохраняются во Flash-память (Preferences/EEPROM).

## 🛠️ Схема подключений (Hardware Setup)

| Компонент | Назначение | Платформа | Пин / Модуль |
| :--- | :--- | :--- | :--- |
| **Main Unit** | Центральный контроллер | ESP32 | Дисплей ST7701S (4.3"), Кнопка SOS (GPIO 17) |
| **Shield Module** | Модуль сектора защиты | ESP8266 | Датчик вибрации (GPIO 14 / D5), NeoPixel LED (GPIO 4 / D2) |

## 🌐 Сетевой протокол (Network API)

Взаимодействие между элементами системы осуществляется по протоколу UDP (порт `1234`).

### Shield → Main
* `PING_<ID>` — регулярное подтверждение присутствия модуля в сети.
* `HIT_<ID>` — сигнал о зафиксированном физическом попадании по сектору.

### Main → Shield
* `NORMAL` — перевод сектора в штатный режим работы.
* `BLINK_RED_<DURATION>` — индикация получения урона / режима перезарядки.
* `BOAT_MODE` — активация резервного/аварийного режима.
* `OFF` — полное отключение индикации (уничтожение объекта).

## ⚡ Быстрый старт

1. **Прошивка Main-модуля:** Скомпилируйте и прошейте код для ESP32. При старте модуль создаст Wi-Fi точку доступа `space_ship_XXXX`.
2. **Прошивка Shield-модулей:** Загрузите прошивку на ESP8266. 
3. **Первичная настройка:** 
   * Если модуль не настроен, он поднимет собственную точку доступа `shield_module_XXXXXX`.
   * Подключитесь к ней с телефона или ПК, перейдите на `192.168.4.1` и укажите ID модуля (1–5), количество светодиодов и параметры подключения к точки доступа Main-модуля.
4. **Запуск:** После перезагрузки модули автоматически найдут центральный узел и войдут в боевой режим.
